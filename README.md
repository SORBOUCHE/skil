# Antigravity Supercharged Plugins & Skills Ecosystem
## منظومة إضافات ومهارات Antigravity المتكاملة

حزمة هندسية شاملة ومتقدمة تضم **15 إضافة متخصصة** ومجموعة من **المهارات الخارقة** المخصصة لبيئة الذكاء الاصطناعي **Google Antigravity**، لتحويل الوكيل الذكي إلى رئيس مهندسين خارق (Lead Architect) قادر على إدارة دورة حياة تطوير البرمجيات كاملة بأقصى سرعة ودقة مع تقليل استهلاك الـ Tokens بنسبة تصل إلى 85%.

## 🌟 أبرز المهارات الخارقة المضمنة (Superhuman Skills)

| المهارة | الوظيفة | التريجر / الاختصار |

| **`chief-expert-agent`** | قيادة وإدارة سرب الـ 15 إضافة عبر مسار هندسي من 8 مراحل. | `"انت رئيس وكلاء خبراء"` أو `/chief-expert-agent` |

## 📦 الإضافات الـ 15 التخصصية (The 15 Core Plugins)

1. **`github-scout`**: مخدم MCP ذكي للبحث في GitHub واستكشاف المكتبات المفتوحة وتنزيل المستودعات وفحص الأكواد.
2. **`context-memory-manager`**: خطاف `SessionStart` لتحميل ملفات ذاكرة المشروع (`PROJECT_CONTEXT.md`, `ADR.md`) تلقائياً.
3. **`ai-agent-toolkit`**: مكتبة أنماط تصميم الوكلاء (ReAct, RAG pipelines, Prompt engineering, Vector databases).
4. **`task-orchestrator`**: إدارة وتفكيك المهام الكبرى تلقائياً إلى مراحل قابلة للتتبع عبر `TASKS.md`.
5. **`devops-autopilot`**: خبير الحاويات (Docker multi-stage) وهندسة Kubernetes و Terraform والبنية التحتية السحابية.
6. **`performance-profiler`**: بوابات فحص حجم الـ Bundles وتحسين مؤشرات الويب (LCP, INP, CLS) وعلاج تسريبات الذاكرة.
7. **`self-healing-debugger`**: خطاف ذكي لاعتراض الأخطاء وانهيارات التشغيل وإصلاحها تلقائياً بدون تدخل يدوي.
8. **`security-sentinel`**: خطاف حراسة أمني يمنع تسريب أي مفاتيح أو أسرار (API Keys, Private Keys) إلى الكود.
9. **`synthetic-data-factory`**: توليد بيانات وهمية علائقية عالية الدقة واختبارات ضغط متقدمة عبر k6 و autocannon.
10. **`api-contract-guardian`**: حماية عقود الـ API ومطابقة OpenAPI 3.1 وخادم محاكاة (Mock Server) سريع.
11. **`smart-refactor-architect`**: إعادة هيكلة وتحديث الأكواد القديمة وتطبيق مبادئ SOLID والمعمارية السداسية.
12. **`live-db-pilot`**: مخدم MCP لقواعد بيانات SQLite وتحليل خطط الاستعلامات وإدارة الترحيلات بأمان.
13. **`autonomous-e2e-tester`**: أتمتة رحلات المستخدم والاختبارات البصرية وفحص واجهات الويب عبر Playwright.
14. **`deep-code-indexer`**: فهرسة الأكواد شجرياً وحساب أثر التعديلات (Impact Analysis) دون استنزاف السياق.
15. **`arabic-rtl-guardian`**: حارس اتجاه الخط العربي والطباعة ثنائية الاتجاه الذي يعمل تلقائياً عند تشغيل النظام.
