## 7-Stage Multi-Disciplinary Swarm Pipeline

Whenever this skill is triggered, immediately follow this standardized execution blueprint:

```
[1. Deep Memory & Context]
       │
[2. Epic Decomposition & Parallel Plan]
       │
[3. Open-Source Scouting & AI Architecture]
       │
[4. Clean Architecture & API Contracts]
       │
[5. Live Database & Synthetic Stress Testing]
       │
[6. Shield Guard & Self-Healing Debugger]
       │
[7. E2E Browser Journey & Cloud DevOps]
```

### Stage 1: Deep Memory & Architectural Mapping
1. **Query Workspace Memory**: Read `PROJECT_CONTEXT.md`, `ARCHITECTURE.md`, or `ADR.md` via `context-memory-manager`.
2. **AST Symbol Mapping**: Call `deep-code-indexer_index_workspace` and `deep-code-indexer_lookup_symbol` to map dependencies, classes, and exported functions without polluting context.

### Stage 2: Task Orchestration & Swarm Dispatch
1. **Epic Breakdown**: Break the user's objective into distinct, atomic phases in `TASKS.md` via `task-orchestrator`.
2. **Identify Parallel Workstreams**: Split independent tasks (e.g., backend schema vs. frontend components) and plan execution using parallel subagents.

### Stage 3: Open-Source Intelligence & AI Design
1. **GitHub Scouting**: Use `github-scout_search_repositories` and `github-scout_get_readme` to find battle-tested patterns, libraries, and reference implementations on GitHub.
2. **AI Agent Systems**: If the project involves AI/LLMs, use `ai-agent-toolkit` to design ReAct loops, vector DB schemas, and grounded RAG pipelines.

### Stage 4: Clean Architecture & Contract Integrity
1. **SOLID & Modernization**: Follow `smart-refactor-architect` rules to keep domain logic decoupled from external I/O and infrastructure.
2. **API Contract Enforcement**: Generate OpenAPI 3.1 specifications and spin up mock servers via `api-contract-guardian` to unblock client-server workflows.

### Stage 5: Live Database & Synthetic Data Verification
1. **Database Schema & Indexing**: Use `live-db-pilot_sqlite_inspect_tables` and `live-db-pilot_sqlite_explain_query` to verify indexes and eliminate full table scans.
2. **Synthetic Fixtures & Stress Testing**: Generate relational mock data and author k6/autocannon performance benchmark scripts via `synthetic-data-factory`.

### Stage 6: Security Sentinel & Self-Healing Debugger
1. **Secret & Vulnerability Shield**: Enforce zero hardcoded credentials via `security-sentinel` and audit dependencies for CVEs.
2. **Automated Triage**: Intercept and resolve any runtime crashes, stack traces, or broken assertions via `self-healing-debugger`.
3. **Performance Gate**: Ensure web vitals (LCP < 2.5s, INP < 200ms, CLS < 0.1) and enforce JS bundle budgets via `performance-profiler`.

### Stage 7: E2E Verification & Cloud Deployment
1. **Playwright User Journeys**: Author resilient end-to-end browser tests and visual snapshot verifications via `autonomous-e2e-tester`.
2. **Production Infrastructure**: Write production-ready multi-stage Dockerfiles, Kubernetes manifests with HPA/probes, and Terraform IaC via `devops-autopilot`.
