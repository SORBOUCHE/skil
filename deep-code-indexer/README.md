# Deep Code Indexer & Symbol Graph Memory 🧠
### إضافة Antigravity لفهرسة شجرة الرموز وإدارة المشاريع البرمجية الضخمة

إضافة متطورة تمنح **Antigravity** معمارية ذاكرة هرمية ثلاثية المستويات (3-Tier Hierarchical Memory) تمكّنه من استيعاب وفهم وتعديل أضخم المشاريع (مئات الملفات) دون إرهاق سياق المحادثة أو تشتت انتباه النموذج.

---

## 🌟 القدرات الأساسية (Core Capabilities)

1. **فهرس شجرة الرموز (Symbol Graph Indexer)**:
   - مسح المشروع البرمجي واستخراج الكلاسات، الدوال، الواجهات، وأنواع البيانات في قاعدة بيانات SQLite محلية مدمجة وسريعة.
2. **الوصول الدقيق المباشر (Sub-Millisecond Symbol Lookups)**:
   - أداة `lookup_symbol` للوصول الفوري لموقع أي دالة أو كلاس بالسطر والملف دون الحاجة لقراءة ملفات عشوائية.
3. **مخطط هيكل الملفات (Structural Outlines)**:
   - أداة `get_file_outline` لمعاينة معمارية أي ملف ضخم واستعراض توقيعات دواله دون تحميل مئات الأسطر في السياق.
4. **تحليل الآثار الجانبية قبل التعديل (Impact Analysis)**:
   - أداة `analyze_symbol_impact` لكشف كافة الملفات التي تستدعي الدالة أو الكلاس قبل تعديلها لمنع كسر التبعيات المتبادلة.

---

## 🛠️ أدوات الـ MCP المتاحة

| الأداة | الوصف |
| :--- | :--- |
| `deep-code-indexer_index_workspace` | فهرسة مجلد المشروع البرمجي واستخراج شجرة الرموز والتبعيات |
| `deep-code-indexer_lookup_symbol` | البحث اللحظي عن أي دالة أو كلاس أو Interface بالاسم |
| `deep-code-indexer_get_file_outline` | استخراج المخطط الهيكلي لأي ملف وأرقام أسطر الدوال |
| `deep-code-indexer_analyze_symbol_impact` | تحليل التبعيات والملفات المتأثرة قبل إعادة الهيكلة |
