# آلة حالات القتال ومتعة التحكم (Combat State Machine & Game Feel)

> سر نجاح ألعاب الأكشن هو "شعور الضربة" (Impact & Juiciness) وليس مجرد نقصان شريط نقاط الصحة.

---

## 1. آلة حالات اللاعب (Player State Machine)

```
        ┌─────────────┐
        │    IDLE     │◄────────┐
        └──────┬──────┘         │
               │ (Move)         │
               ▼                │ (Recovered)
        ┌─────────────┐         │
        │     RUN     │         │
        └──────┬──────┘         │
               │ (Attack)       │
               ▼                │
     ┌──────────────────┐       │
     │ ATTACK 1 (Combo) ├───────┤
     └─────────┬────────┘       │
               │ (Next timing)  │
               ▼                │
     ┌──────────────────┐       │
     │ ATTACK 2 (Combo) ├───────┤
     └─────────┬────────┘       │
               │ (Finisher)     │
               ▼                │
     ┌──────────────────┐       │
     │ ATTACK 3 (Heavy) ├───────┘
     └──────────────────┘
```

## 2. الركائز الخمس لمتعة القتال الحركي (Combat Game Feel)

### 1. إيقاف الإطار عند الضربة (Hitstop / Impact Freeze)
عند إصابة ضربة قوية لهدف، يتم تجميد حركة اللاعب والعدو معاً لعدة إطارات (بين 0.05 إلى 0.08 ثانية). هذا التجميد الدقيق هو ما يعطي الإحساس بثقل وقوة السلاح:
```javascript
let hitstopTimer = 0;
function triggerHitstop(duration = 0.06) {
  hitstopTimer = duration;
}
// داخل حلقة التحديث:
if (hitstopTimer > 0) {
  hitstopTimer -= delta;
  return; // تجاوز تحديث الحركة لإيقاف الإطار مؤقتاً
}
```

### 2. التراجع والارتداد (Knockback & Stagger)
- العدو لا يقف جامداً عند تلقي الضربة، بل يتم دفعه للخلف باتجاه متناسب مع اتجاه الضربة:
```javascript
enemy.velocity.addScaledVector(attackDirection, knockbackForce);
enemy.playStaggerAnimation();
```

### 3. إطارات الحصانة أثناء المراوغة (Invincibility Frames / I-Frames)
- عند الضغط على زر المراوغة (Dodge Roll)، يُمنح اللاعب حصانة تامة من أي ضرر لمدة 0.25 ثانية مع كسر فوري لأي حركة ضربة سابقة (Action Cancel).

### 4. نظام تثبيت الهدف (Lock-On Target)
- عند الضغط على زر الـ Lock-On (الزر الأوسط للماوس أو زر R3 في يد التحكم)، تلتف الكاميرا وتتجه الضربات تلقائياً نحو أقرب وحش في المحيط.

### 5. نظام الصد والارتداد العكسي (Parry System)
- إذا ضغط اللاعب على زر الصد (Block) قبل وصول ضربة العدو بأقل من 0.15 ثانية، يتم عكس الضربة، وإصابة العدو بالدوار (Stunned)، وتشغيل فلاش ضوئي أبيض مع صوت معدني حاد.
